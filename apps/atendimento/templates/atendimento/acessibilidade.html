Acessibilidade

O SAG-Cidadão segue o eMAG 3.1 (Modelo de Acessibilidade em Governo Eletrônico) e as diretrizes internacionais WCAG 2.1, nível AA, para que todas as pessoas, inclusive com deficiência, consigam usar o serviço.

Atalhos de teclado

AtalhoLeva para
1Conteúdo principal da página
2Menu principal
3Busca (nas telas sem campo de busca, leva à consulta de protocolo)
4Rodapé

Como usar: no Chrome e no Edge, Alt + número; no Firefox, Alt + Shift + número; no Safari, Ctrl + Option + número.

Recursos

  • Alto contraste, no topo de todas as páginas. A escolha fica guardada no seu navegador.
  • Todas as funções podem ser usadas só pelo teclado (Tab avança, Shift+Tab volta), com destaque visível no item em foco.
  • Para aumentar o texto, use o zoom do navegador: Ctrl + + (e Ctrl + 0 para voltar).
  • Compatível com leitores de tela, como NVDA (Windows) e Orca (Linux). Formulários, mensagens de erro e mapas têm descrições próprias para eles.
  • O mapa é opcional: o endereço escrito é suficiente para abrir uma solicitação.

Como avaliamos

Cada versão passa por uma auditoria automática de todas as telas com o axe-core (regras WCAG 2.1 A e AA). Ferramentas automáticas encontram parte dos problemas; por isso também testamos a navegação só por teclado.

Encontrou alguma barreira?

Conte para nós pelo atendimento da Prefeitura de Porto Velho, informando a página e o que aconteceu. Sua mensagem ajuda a corrigir o problema para todos.
